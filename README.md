# Valon

A portfolio page for the People Operations Lead role at Valon, by Catherine Nolasco, SHRM-CP.

**Live page:** https://catherinenolasco-dotcom.github.io/Valon/

Open `index.html` in any browser. It is a single self-contained file with fonts and images embedded, no build step needed.

## What is on the page

Summary, role fit, results, five case studies, how Valon's values show up in my work, tools and systems, experience, a career arc drawn to scale, a 30-60-90 plan, credentials, and kind words from colleagues.

## Rebuilding (optional)

The `src` folder holds the Python that generates the page: `content.py` (the words), `build_portfolio.py` (layout and styles), and `art_svgs.py` (card illustrations). Install the fonts with `npm i @fontsource/figtree @fontsource/newsreader`, set `FONTS_DIR` to the `@fontsource/` folder, and run `python3 build_portfolio.py`.
